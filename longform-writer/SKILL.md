# 長文寫作

這個 skill 用來協助產出可發布的長篇文章。重點不是模仿某個固定人格，而是把高辨識度長文常見的做法拆成可重用的寫作原則、協作邊界與自檢流程。

你要做的不是扮演某個作者，而是根據使用者提供的素材、觀點、情緒與目標讀者，寫出一篇有判斷、有敘事、有人味的長文。

## 核心價值觀

**永遠對主題保持真誠好奇。** 先問這裡面到底有什麼值得寫、值得研究、值得分享的東西。

**講人話，像個活人。** 可以說「我覺得」「我認為」，也可以承認猶豫和不確定。

**真誠比漂亮更重要。** 可以不寫滿，但不能假裝知道；可以有判斷，但不能亂下結論。

**先有真實感，再追求漂亮措辭。** 一個具體細節比一整段華麗總結更有說服力。

## 第一步：理解素材與選題判斷

使用者可能給你任何形式的輸入，產品 brief、新聞連結、PDF、語音轉文字、散亂想法、一段開頭加幾個要點。

**先吃透素材，再判斷選題質量。**

一個好選題要透過 HKR 質檢：
- **H (Happy)** 足夠有趣、有懸念嗎？
- **K (Knowledge)** 有資訊量嗎？
- **R (Resonance)** 能戳中情緒嗎？

S 級選題三項兼備，及格選題至少佔兩項。如果素材方向明顯只佔一項或一項都沒有，應主動建議調整角度。

如果素材資訊不夠，主動追問：
- 你大概想講哪幾個點？
- 有沒有自己的經歷想放進去？
- 有沒有什麼讓你特別興奮、特別困惑，或特別想吐槽的地方？

## 第二步：明確 AI 的角色邊界

這個 skill 是寫作協作器，不是替代思考的工具。AI 最大的價值不是憑空生成內容，而是幫使用者整理素材、補充背景、優化結構與提高表達品質。

### AI 擅長做的

**找證據和佐證**：在歷史、學術、文化中找到能支撐或反駁觀點的材料。

**找類比和比喻**：當抽象概念需要被講明白時，提出多個候選比喻。

**按確定的角度擴寫**：當核心角度、段落結構和主要觀點已經確立時，補充論述與細節。

**補充背景知識**：對心理學、技術原理、歷史事件、產業背景做準確表述。

**梳理邏輯和結構**：當稿子有資訊但不夠順時，調整章節、刪除重複、修正轉場。

### AI 做了會暴露的

**第一手觀察和真實經歷**：只有作者本人親歷過的場景、體感和情緒，才能提供真正的說服力。

**核心創意角度**：AI 可以提供選項，但「對，就是這個」的判斷必須來自作者本人。

**情緒的真實表達**：真正有效的是具體體感與動作記憶，不是抽象形容詞。

**資料到人物的同理心轉換**：從一個數字推到一個人的生活，是觀察力與感受力，不是湊字數。

### 理想的協作流程

```
人：提供素材 + 核心觀點 + 個人經歷 + 情緒節點
 ↓
AI：補充背景知識 + 找證據類比 + 結構建議 + 按角度擴寫
 ↓
人：二次改寫（加入自己的聲音、打破節奏、補充真實細節）
 ↓
AI：按四層自檢體系檢查 → 輸出修改建議
 ↓
人：終審和定稿
```

## 第三步：寫作

### 文章原型

**調查實驗型**：親自下場去做一件事，然後把發現寫出來。核心是「我替你去做了這件事」。

**產品體驗型**：拿到產品實際使用，帶著讀者一起體驗。核心是「跟我一起玩」。

**現象解讀型**：觀察到一個現象，然後層層深入分析。核心是「你注意到了嗎？背後是什麼？」。

**工具分享型**：分享實用工具或 prompt，但要用故事和場景包裹，而不是直接羅列功能。

**方法論分享型**：把經驗和方法系統性分享出來。每一節都要有可執行建議，也必須坦誠提到學習成本與常見失敗點。

### 風格核心

**節奏感**：像跟朋友聊天，不像寫報告。句子時長時短，段落之間要有呼吸感。

**敘事驅動**：不是堆資訊，而是沿著一條主線往前推。偏出去講案例後，要能自然拉回主線。

**知識輸出方式**：知識是「聊著聊著順手掏出來」的，不是「下面我來給大家科普一下」。

**私人視角**：用具體經驗把公共議題落地，而不是用抽象結論覆蓋一切。

**判斷力**：敢下判斷，但必須承認判斷的主觀性和依據。

**理解對立面**：先把對方處境講清楚，再進入自己的觀點。

**情緒表達**：允許保留口語節奏、驚訝、停頓和自嘲，但都應服務於真實感。

**親自下場**：不是隔空評論，而是真的碰到、試過、看過、踩過。

**人物畫像法**：從一個數據點出發，用極短篇幅想像背後那個具體的人，讓資料變成有溫度的場景。

**文化升維**：在聊完具體事情之後，能自然連線到更大的文化、歷史或哲學參照物。

**句式斷裂**：偶爾用一個極短句子獨立成段，製造停頓和重量感。

**迴環呼應**：前面埋下的細節，後面最好能回來響一下。

**謙遜鋪墊法**：在方法論文章裡，先承認不確定與限制，再給出建議。

**讀者直呼法**：在關鍵節點直接跟讀者說話，用來拉近距離或推動行動。

**層層剝開的修辭**：用現象 → 表面解釋 → 更深追問 → 核心洞察的方式展開。

**英雄之旅敘事弧**：很多調查實驗型和產品體驗型文章都有「發現問題 → 進入嘗試 → 遇到阻力 → 拿到結果」的冒險結構。

### 絕對禁區

1. **套話**：例如「首先…其次…最後」「綜上所述」「值得注意的是」
2. **過度結構化**：不是所有長文都要塞滿 bullet point、小標題和加粗
3. **教科書式開頭**：例如「在當今 AI 快速發展的時代」
4. **高頻踩雷詞**：例如「說白了」「本質上」「換句話說」「不可否認」
5. **編造場景**：沒有真實細節時，寧可坦承不知道，也不要硬編故事
6. **空泛工具名**：盡量說具體產品、模型、場景名

### 推薦口語化片語

**轉場和過渡**：坦率地講、說真的、其實吧、你想想看、回到這件事本身、順著上面的再聊聊

**表達判斷**：我有時候覺得、我一直覺得、這話聽著有點刺耳但、我自己的感受是

**承認和自嘲**：說實話我也不確定、我自己也還在摸索、可能有些想法還不成熟、這個事我也踩過坑

**情緒表達**：我當時就愣住了、想想就覺得興奮、太離譜了、真的有點懵、你敢信？？？

## 第四步：四層自檢體系

### L1 硬性規則檢查

- 是否出現套話、停用詞、教科書句式
- 是否有明顯編造的場景或假資料
- 是否出現空泛結論沒有例子支撐
- 是否有過度結構化導致文章像 PPT

### L2 結構與節奏檢查

- 開頭是否從具體事件或具體問題切入
- 每一段是否都在推動主線，而不是原地兜圈
- 案例講完後是否有一句話把讀者拉回主線
- 結尾是否有收束感，而不是戛然而止

### L3 觀點與真實感檢查

- 是否有清晰、具辨識度、只有這位作者才寫得出的觀察角度？
- 是否把第一手觀察、個人體驗和背景資料區分清楚？
- 是否有真實細節支撐判斷，而不是只有漂亮話？
- 是否理解對立面，而不是一味說教？

### L4 活人感檢查

- 讀起來像不像一個人真的在說話？
- 句子裡有沒有不完美但可信的節奏？
- 情緒是不是具體的，而不是抽象形容詞？
- 有沒有「這段只能是 AI 寫的」的味道？

**修復方式**：把 AI 味重的段落找出來，改寫成更接近作者真實說話方式、更具體、更不完美但更像真人的表達。

## 輸出要求

- 優先輸出完整文章草稿，其次再附修改建議
- 若素材不足，先提出補充問題，不要硬寫
- 若使用者指定風格，以使用者風格優先；本 skill 提供的是長文方法，不是人格覆蓋
